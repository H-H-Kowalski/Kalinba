# 微信云函数部署说明（演奏分享）

## 1. 已生成的云函数目录

- `cloudfunctions/createPerformanceRecord`
- `cloudfunctions/getPerformanceRecord`
- `cloudfunctions/cleanupPerformanceRecords`

对应前端调用：
- `createPerformanceRecord`：上传录制并返回 `recordId`
- `getPerformanceRecord`：按 `recordId` 拉取演奏数据
- `cleanupPerformanceRecords`：定时清理过期数据

另外，`upsertUserAchievementStats` 已扩展为挑战进度档案：保存每关最高分、星数、连击、累计音符、解锁关卡和成就。更新客户端后，须重新上传部署这个云函数。

## 2. 云数据库集合

创建集合：`performance_records`

建议索引：
- `recordId`（唯一）
- `ownerOpenId`
- `createdAtMs`
- `expireAtMs`

挑战与成就继续使用集合：`user_achievement_stats`。建议索引：

- `openid`（唯一）

## 3. 云函数部署步骤

1. 在微信开发者工具中开启云开发环境。
2. 将本项目 `cloudfunctions` 目录导入为云函数根目录。
3. 逐个云函数安装依赖并上传部署（开发者工具可右键云函数“上传并部署”）。
4. 为 `cleanupPerformanceRecords` 配置定时触发（建议每天 1 次）。
5. 更新版本时重新上传部署 `upsertUserAchievementStats`；该函数会兼容已有旧档案并自动补齐新字段。

## 4. 前端已接入点

- `GameScene`：录制/停止/分享/回放
- `KalimbaKey`：按键事件采集
- `PerformanceCloudService`：云函数调用
- `PerformanceShareLaunch`：启动时读取分享 `rid` 参数

## 5. 分享参数格式

- 分享 query：`rid=<recordId>`
- 好友打开后自动进入 `playscene` 并尝试回放

## 6. 限制参数（已实现）

- 最长录制时长：`180000ms`（3 分钟）
- 最大事件数：`6000`
- 最大编码长度：`128KB`
- 云端频率限制：每个用户每分钟最多创建 `5` 条

## 7. 注意事项

- 云函数 `getPerformanceRecord` 目前默认返回公开记录；如需私密/拉黑等策略，后续加鉴权字段。
- 目前 `eventsEncoded` 存的是 JSON 字符串，后续可升级为压缩编码（如 base64+压缩）以降低存储成本。
- 若你修改了云函数名称，需要同步更新 `assets/scripts/manager/PerformanceCloudService.ts`。
