# 拇指琴演奏家软件V1.0 软件说明书

## 一、引言

### 1.1 软件概述

拇指琴演奏家软件V1.0（以下简称"本软件"）是一款面向拇指琴（Kalimba）爱好者与普通用户的移动端互动演奏软件。本软件以微信小游戏为运行载体，提供 17 键卡林巴琴的触控演奏体验，支持多种音色风格切换、曲谱查看与翻页、演奏录制与分享等功能，实现了从弹奏、录制到社交分享的完整使用闭环。

## 二、软件安装与启动

### 2.1 安装方式

本软件为微信小游戏，无需单独安装，用户可通过以下方式进入：

1. **搜索进入**：打开微信，进入「发现 → 小程序」，搜索"拇指琴演奏家"，点击进入即可。
2. **扫码进入**：使用微信扫描软件的小程序码/小游戏码，即可直接跳转至本软件。
3. **分享链接进入**：点击好友分享的演奏链接，自动打开本软件并进入回放模式。

### 2.2 启动流程

用户通过上述方式打开本软件后，首先进入首页界面，随后可选择"开始演奏"进入演奏界面，或进入"设置"调整音色与偏好参数。

## 三、功能说明

### 3.1 首页界面

首页是用户进入软件后的第一个界面，提供以下功能入口：

- **开始演奏**：点击"开始"按钮，切换至演奏场景（playscene）。
- **设置**：点击"设置"按钮，进入设置场景（settingscene），可调整音色、翻页偏好等。
- **关于**：点击"关于"按钮，弹出关于面板，显示作者微信号与邮箱地址，支持一键复制。

首页同时负责初始化分享落地参数捕获，当用户通过好友分享链接进入时，会自动记录分享参数，以便在演奏界面执行回放。

### 3.2 演奏界面

演奏界面是本软件的核心功能页面，包含以下主要区域和功能：

#### 3.2.1 卡林巴琴键区域

界面下方排列着 17 个琴键，按照卡林巴标准 V 形布局排列——中间琴键最长，两侧依次缩短，顶部对齐。每个琴键上标注了简谱数字和高低音点标识，对应真实卡林巴的音符映射（从左至右：D6、B5、G5、E5、C5、A4、F4、D4、C4、E4、G4、B4、D5、F5、A5、C6、E6）。

用户触摸（点按）琴键即可发声：
- **视觉反馈**：按下时琴键变为半透明，松开后恢复。
- **触觉反馈**：在支持振动的设备上，每次按键触发轻微短振。
- **音频播放**：通过 WebAudio 合成引擎实时生成卡林巴音色的声音，无需加载任何外部音频文件。

支持多键同时触控（多指同时弹奏），各键互不干扰。

#### 3.2.2 录制与分享控制

演奏界面顶部/侧方提供录制相关的操作按钮：

- **开始录制 / 停止录制**：点击切换录制状态。录制时会记录每个琴键的按压时间和键位索引，最长支持 3 分钟、最多 6000 个音符事件。录制中按钮切换为"停止"图标/文字。
- **回放**：停止录制后，可点击回放按钮聆听刚才的演奏。回放时琴键会自动模拟按压视觉效果（半透明 + 缩放脉冲），且琴键区域进入锁定状态，防止用户误触。
- **分享**：将录制的演奏上传至微信云端，并拉起微信分享面板，生成带参数的分享卡片。好友点击分享卡片后可打开本软件自动回放该段演奏。

#### 3.2.3 曲谱背景区域

演奏界面上方为曲谱显示区域，支持以下功能：

- **默认曲谱**：软件内置默认曲谱图片，打开即可看到。
- **自定义曲谱**：点击"选图"按钮，调起微信相册选择器，最多选取 5 张图片作为自定义曲谱。选择后自动替换默认曲谱，关闭软件后下次进入会自动恢复上次选择的图片。
- **翻页浏览**：支持左右滑动（横向翻页）或上下滑动（纵向翻页）切换曲谱页面。底部显示圆点指示器标识当前页位置，点击圆点可跳转。
- **长图滚动**：若选择的是一张长图（高度远超宽度），系统自动切换为纵向滚动模式，支持手动上下拖动浏览。
- **自动滚动**：开始录制时，曲谱自动从顶部开始滚动，滚动速度可在设置中调节。
- **页码显示**：右侧显示当前页码/总页数（如"1/3"）。

### 3.3 设置界面

设置界面为独立场景，提供以下可配置项：

#### 3.3.1 音色切换

提供 5 种音色风格预设，点击即可切换：

| 预设名称 | 音色特点 |
|----------|----------|
| 明亮 | 起音快速、衰减短促，高频泛音突出 |
| 流行 | 均衡适中，适合大众曲目 |
| 深沉 | 起音较慢、衰减悠长，低频饱满 |
| 清脆 | 极短起音、泛音明亮，节奏感强 |
| 空灵 | 尾韵悠长、瞬态弱化，带有空气感 |

当前选中的音色前方显示"✓"标记。

#### 3.3.2 曲谱翻页偏好

提供两种翻页模式供用户选择：

- **横向翻页**：左右滑动切换曲谱页面。
- **纵向翻页**：上下滑动切换曲谱页面。

当曲谱为单张长图时，将强制使用纵向滚动模式，此时横向翻页选项不可选，并给出提示。

#### 3.3.3 自动滚动速度

提供输入框，可设置自动滚动/翻页的速度值（范围 0~100，默认 50）。数值越大滚动越快。

#### 3.3.4 恢复默认

点击"恢复默认"按钮，将音色、翻页偏好、滚动速度等所有设置恢复为出厂默认值。

#### 3.3.5 返回

点击返回按钮可回到上一个场景（首页或演奏界面，取决于从哪里进入设置）。

### 3.4 演奏录制与分享

本软件实现了完整的演奏录制、回放与社交分享流程：

#### 3.4.1 录制流程

1. 在演奏界面点击"开始录制"按钮，进入录制状态。
2. 系统记录每次琴键按下的时间戳（毫秒精度）和键位索引。
3. 录制期间，曲谱区域开始自动滚动（若启用）。
4. 点击"停止录制"按钮结束录制，系统提示录制时长和音符数量。

录制限制：最长 3 分钟（180 秒），最多 6000 个音符事件，编码后数据不超过 128KB。

#### 3.4.2 回放流程

1. 录制完成后，点击"回放"按钮。
2. 系统按照记录的时间序列依次触发各琴键播放。
3. 回放中琴键呈现自动按压效果（透明度变化 + 缩放脉冲动画），曲谱区域切换为分享回放专用背景。
4. 回放期间琴键区域锁定，设置按钮和返回按钮变为不可点击状态。
5. 回放结束后自动解除锁定，恢复曲谱显示。

#### 3.4.3 分享流程

1. 录制并停止后，点击"分享"按钮。
2. 系统对录制数据进行校验与编码，通过微信云函数上传至云端数据库。
3. 云端返回唯一记录 ID，系统自动拉起微信转发面板。
4. 好友收到分享卡片并点击进入后，软件自动获取记录 ID，从云端下载演奏数据，进入自动回放模式。

## 四、操作流程

### 4.1 基本演奏流程

```
打开微信小游戏
    ↓
进入首页
    ↓
点击"开始演奏"
    ↓
进入演奏界面
    ↓
触摸琴键进行弹奏（支持多指同时弹奏）
    ↓
弹奏完毕，可点击"返回"回到首页
```

### 4.2 录制与分享流程

```
进入演奏界面
    ↓
点击"开始录制"
    ↓
弹奏琴键（系统记录按键时间与键位）
    ↓
点击"停止录制"
    ↓
[可选] 点击"回放"试听
    ↓
点击"分享" → 上传云端 → 拉起微信分享面板
    ↓
好友收到分享 → 打开 → 自动回放
```

### 4.3 设置调整流程

```
首页或演奏界面 → 点击"设置"
    ↓
进入设置界面
    ↓
选择音色（明亮/流行/深沉/清脆/空灵）
    ↓
选择翻页偏好（横向/纵向）
    ↓
调整自动滚动速度（0~100）
    ↓
点击"返回"回到上一场景，设置自动保存
```

### 4.4 自定义曲谱流程

```
进入演奏界面
    ↓
点击"选图"按钮
    ↓
从手机相册选择图片（最多 5 张）
    ↓
曲谱区域自动替换为所选图片
    ↓
左右/上下滑动翻页浏览
    ↓
下次进入自动恢复上次选择
```

## 五、运行环境要求

### 5.1 运行平台

- **平台**：微信小游戏
- **微信版本**：建议 8.0 及以上
- **微信基础库**：建议 2.19 及以上（WebAudioContext 需要基础库 ≥2.19）

### 5.2 设备要求

- **设备类型**：支持触控操作的智能手机（Android / iOS）
- **音频能力**：设备需支持音频播放（WebAudio）
- **网络**：演奏录制分享功能需联网（上传/下载演奏数据使用微信云函数）；离线状态下弹奏与设置功能可正常使用
- **存储**：本软件使用本地存储（localStorage）保存用户设置与曲谱选择，占用空间极小

### 5.3 开发环境

| 开发工具 | Cocos Creator 3.8.6 |

| 构建目标 | 微信小游戏（wechatgame） |
| 云服务 | 微信云开发（云函数 + 云数据库） |
