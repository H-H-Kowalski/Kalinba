## 二、开发背景与目的

本软件面向拇指琴（Kalimba）爱好者与普通用户，提供轻量化、低门槛的移动端演奏体验。用户可在微信小游戏中进行琴键触控演奏、切换音色风格、查看/切换曲谱并进行个性化设置。  
项目目标如下：

1. 提供稳定的多键触控演奏体验；
2. 在微信小游戏环境中实现低延迟、可调音色的合成发声；
3. 支持曲谱显示与翻页模式，适配长图曲谱场景；
4. 支持基础设置持久化，便于跨场景与下次启动恢复；
5. 提供演奏录制、回放与社交分享能力，通过微信云开发实现演奏数据的云端存取与好友间传播。

## 三、软件功能概述

### 3.1 主页与场景切换

- 提供首页、演奏页、设置页等界面。
- 支持场景间状态流转与返回逻辑管理。

### 3.2 卡林巴琴键交互

- 17 键映射与触控事件处理；
- 按下/抬起视觉反馈；
- 并发触控下的发声与触觉反馈控制。

### 3.3 音频播放与合成引擎

- 采用 `SynthKalimbaEngine` 进行 WebAudio 合成发声；
- 通过 `AudioManager` 管理播放入口、音量、预设参数与兜底策略；
- 支持多种音色风格（如明亮、流行、深沉、清脆）；
- 在不支持合成时可回退到采样播放方案；
- 提供音频调试日志开关，便于真机排查。

### 3.4 曲谱显示与翻页

- 支持默认曲谱显示与用户自定义选图；
- 支持横向/纵向翻页偏好；
- 针对单张长图支持纵向滚动与分页体验优化；
- 支持页码、指示点、上一页/下一页导航。

### 3.5 设置与持久化

- 音频设置存储（音色、音量、参数模式）；
- 曲谱翻页偏好存储；
- 字体与文案等展示配置管理；
- 运行时状态同步与跨场景恢复。

### 3.6 演奏录制与回放

- 支持在弹奏过程中实时录制琴键事件（时间戳 + 键位索引），最长 3 分钟、最多 6000 个音符事件；
- 录制完成后可立即回放，系统按时间序列自动触发各琴键发声并呈现按压视觉反馈；
- 回放期间琴键区域自动锁定，防止用户误操作干扰回放。

### 3.7 演奏分享

- 将录制数据编码后通过微信云函数上传至云端数据库；
- 上传成功后自动拉起微信分享面板，生成带参数的分享卡片；
- 好友点击分享卡片进入本软件后，自动从云端下载演奏数据并立即开始回放；
- 支持启动参数与 onShow 参数双通道捕获，确保冷启动与热切换场景均可正确消费分享数据。

## 四、系统架构与技术实现

### 4.1 总体架构

软件采用组件化脚本架构，按“视图层 + 管理层 + 存储层”组织：

- 视图层：`assets/scripts/view/`  
  负责 UI 展示、交互事件和界面状态刷新。
- 管理层：`assets/scripts/manager/`  
  负责音频引擎、资源管理、场景管理、平台适配与设置管理。
- 交互节点脚本：`assets/scripts/KalimbaKey.ts` 等  
  负责具体琴键行为与事件响应。

### 4.2 关键模块

- 音频合成模块：`SynthKalimbaEngine.ts`
  - 初始化/维护 WebAudioContext；
  - 按键频率映射、包络与泛音建模；
  - 用户手势触发播放与 `resume` 时序控制。

- 音频管理模块：`AudioManager.ts`
  - 统一音频播放入口；
  - 合成与采样兜底切换；
  - 音色预设参数下发与音量控制；
  - 运行日志与状态观测。

- 曲谱显示模块：`SheetMusicBackground.ts`
  - 曲谱资源加载、轮播、翻页与长图滚动；
  - 翻页模式策略与运行时状态同步。

- 设置存储模块：`AudioSettingsStore.ts`、`SheetSettingsStore.ts`、`FontSettingsStore.ts`
  - 本地存储读写；
  - 默认值、合法性校验与恢复。

- 演奏录制模块：`PerformanceRecorder.ts`、`PerformanceTypes.ts`
  - 实时记录琴键按压事件（毫秒级时间戳 + 键位索引）；
  - 录制时长与事件数上限控制；
  - 数据校验、JSON 编码与解码；
  - 体积上限保护（128KB）。

- 演奏回放模块：`PerformancePlayer.ts`
  - 基于 setTimeout 的时间序列调度；
  - 按记录时刻逐一触发 AudioManager 发声并驱动琴键视觉反馈；
  - 回放结束自动清理定时器与状态。

- 云端存取模块：`PerformanceCloudService.ts`
  - 封装 `wx.cloud.callFunction` 调用；
  - 创建记录（`createPerformanceRecord` 云函数）；
  - 查询记录（`getPerformanceRecord` 云函数）。

- 分享落地模块：`PerformanceShareLaunch.ts`
  - 初始化微信云开发环境；
  - 捕获启动参数与 `onShow` 参数中的记录 ID；
  - 通过 localStorage 暂存待消费的分享记录 ID。

### 4.3 云端服务

本软件使用微信云开发（CloudBase）实现演奏数据的云端存取，相关云函数部署于微信云端：

- `createPerformanceRecord`：接收编码后的演奏数据并写入云数据库，返回唯一记录 ID。
- `getPerformanceRecord`：根据记录 ID 查询演奏数据并返回给客户端。
- `cleanupPerformanceRecords`：定时清理过期的演奏记录，控制存储量。

### 4.4 平台适配

- 微信环境能力通过 `WeChatNative.ts` 封装访问；
- 采用微信小游戏 `WebAudioContext` 能力进行发声；
- 适配震动、选图、剪贴板等微信原生接口；
- 微信云开发 SDK 初始化与云函数调用封装；
- 分享卡片参数携带与解析；
- 对非支持环境提供能力检测和兜底处理。
