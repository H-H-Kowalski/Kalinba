# 任务成就系统设计（Kalinba）

## 1. 目标

为当前拇指琴玩法补充一个低成本、高收益的成长系统，用于提升留存与审核材料完整度。  
系统围绕“每日任务 + 成就徽章 + 进度反馈”展开，不引入付费要素，不涉及排行榜强依赖。

## 2. 系统定位

- 面向用户：给出清晰目标，减少“玩一次就走”的情况。
- 面向产品：形成可持续的日常活跃入口。
- 面向审核：可独立描述为一个完整系统，且可提供独立截图。

## 3. 功能范围

### 3.1 每日任务

- 每日 0 点刷新（本地时间）。
- 默认显示 3 个任务，可后续扩展到 5 个。
- 任务可追踪进度，完成后可领取“徽章点数”（非货币，不可交易）。

示例任务：
- 完成 1 次录制并停止。
- 完成 1 次回放。
- 连续按对 20 个音符（教学/评分模式）。
- 在任意模式下弹奏累计 3 分钟。

### 3.2 成就系统

- 长期成就，不每日重置。
- 每个成就分 1~3 档（例如“录制大师 I/II/III”）。
- 达成后点亮徽章并记录达成时间。

示例成就：
- 首次录制完成。
- 累计回放 10 次。
- 累计弹奏 1000 个音符。
- 任意歌曲达到 A 评级。

### 3.3 任务面板

- 首页或弹奏页提供“任务”入口按钮。
- 面板展示：任务标题、进度、完成状态、成就徽章墙。
- 可关闭，不打断主流程。

## 4. 数据结构建议（TypeScript）

```ts
export interface DailyTaskState {
  id: string;
  dateKey: string; // YYYY-MM-DD
  progress: number;
  target: number;
  completed: boolean;
  claimed: boolean;
}

export interface AchievementState {
  id: string;
  level: number;
  progress: number;
  target: number;
  unlocked: boolean;
  unlockedAt?: number;
}

export interface TaskSystemSnapshot {
  dailyTasks: DailyTaskState[];
  achievements: AchievementState[];
  badgePoints: number; // 徽章点数（仅展示，不可消费）
  lastRefreshDateKey: string;
}
```

## 5. 事件接入点（与现有代码对应）

建议从以下节点更新任务进度：

- 录制开始/停止：`GameScene.onToggleRecordClick` / `onStopRecordClick`
- 回放开始：`GameScene.onReplayLastClick`
- 按键触发：`KalimbaKey.onTouchStart`（或 `PerformanceRecorder.recordKey`）
- 分享成功：`GameScene.onShareRecordClick` 成功回调
- 评分结果：后续评分系统结算回调（A/B/C/S）

## 6. 存储方案

- 第一阶段使用 `sys.localStorage` 存储任务快照（低成本）。
- 后续可选云端同步（微信云开发）：
  - 优点：跨设备同步、数据不丢。
  - 风险控制：失败时回退本地缓存，不阻断主流程。

## 7. UI 截图建议（用于审核）

可提供至少 2 张不重复截图：

1. 任务面板截图：展示“每日任务列表 + 进度条 + 已完成状态”。
2. 成就面板截图：展示“徽章墙 + 已解锁成就 + 未解锁成就”。

可作为“任务成就系统”独立模块，避免与弹奏主界面截图重复。

## 8. 审核提交可用描述（每段 >= 30 字）

### 8.1 任务系统描述

游戏内提供每日任务系统，玩家可通过录制演奏、回放作品、连续弹奏等行为完成任务并领取徽章点数。任务进度实时更新，次日自动刷新，帮助玩家形成持续体验与目标导向。

### 8.2 成就系统描述

游戏内提供长期成就系统，玩家在演奏、录制、回放和挑战过程中可逐步解锁多档成就徽章。系统会记录用户达成进度与解锁时间，突出成长反馈并增强玩法持续性。

## 9. 非商业化声明（与当前产品一致）

本系统不包含元宝、金币、钻石、商城、会员、红包等商业化设计。  
“徽章点数”仅用于展示任务成长，不可充值、不可兑换、不可交易。

## 10. 迭代建议

- V1（1~2天）：本地任务 + 成就展示 + 基础进度更新。
- V2（2~4天）：任务刷新规则完善 + 动画反馈 + 埋点统计。
- V3（可选）：云端同步与多设备一致性。
